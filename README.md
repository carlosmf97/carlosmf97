## ⚙️ Real-time telemetry & machine health

Leading engineering on a real-time monitoring and predictive-maintenance platform for marine engines and energy plants, running 24/7 on vessels at sea, on-site plants and a cloud fleet layer. Sensor and PLC telemetry over MQTT, time-series storage and processing, per-signal health trending, time-to-alarm projection, maintenance-priority dashboards, live single-line diagrams of power plants, push alarms straight to operators' phones, and LLM-assisted analysis of engine data.

> The interesting problems live in the gap between *"we log data"* and *"we know which machine to service next."*

## 🤖 AI-native engineering

Building with agents every day since early 2023: Cursor from launch, then Claude Code and OpenAI Codex. I engineer the skills, MCP tools, subagents and context that keep them productive in a large codebase and on team conventions, and I ship LLM features to production.

- **[FlowState](https://github.com/carlosmf97/flowstate):** local-first agent orchestrator. Assign a task in Trello, Linear, Jira or GitHub Issues and Claude Code implements it in Docker, tests it, opens the PR and answers the review comments.
- **[multiwork](https://github.com/carlosmf97/multiwork):** a lead agent runs researcher, architect and build/review agent pairs in parallel.
